## 一、今天要掌握的四点

1. 零基础先用网页端工具，不要一上来装 Cursor 这类本地 IDE。Bolt.new 这类工具在浏览器里直接跑，打开就能用，不用配环境、不用装 Node。
2. 提示词驱动开发：用话把需求描述清楚，AI 直接产出可运行的代码，不需要先学语法。
3. 迭代而不是重写：效果不对就接着说"把颜色改成蓝的""这里加一个按钮"，让 AI 在原基础上改，别推倒重来。
4. 一键部署：工具自带 Publish，点一下就能拿到公开网址，不用买服务器、不用配域名。

## 二、学完能做出什么

一个属于自己的小工具，有公开链接，能发给任何人打开。

今天的具体目标：把"宜宾天气文字版"做成一个小页面，输入城市或直接展示当天天气要点，点一下生成一段可以直接转发的文字。

## 三、操作步骤（按这个顺序走）

1. 打开 bolt.new，注册一个免费账号；
2. 在对话框里写需求，越具体越好，例如：
   "做一个单页网站，标题是宜宾今日天气，页面里有一个输入框和一个按钮，点按钮后显示一段天气文字，文字可以编辑复制"
3. 看效果，不满意就继续用话提修改意见，一次只改一件事；
4. 满意后点 Publish，拿到公开链接；
5. 把链接和截图存进 `素材\`，再传到 GitHub 仓库 `yibin-weather` 里。

## 四、和 FDE 的关系

这一讲解决的是"能不能自己交付一个东西"的问题。FDE 第一层能力是工程基本功，短期内补不上大工程，但可以用 AI 工具先做到"一个人能交付一个小系统"，这就是作品集里的第一个证据。

面试时能说的话：需求我自己定义、原型我自己搭、上线我自己发布，链接在这里。

## 五、常见卡点

- 生成的页面空白：多半是提示词没说清布局，补一句"页面居中，白底，字号大一点"；
- 改一处坏一片：把之前满意的版本存一份，改动前先备份；
- Publish 后打不开：检查是否点了 Deploy 而不是 Preview，链接要以 https 开头；
- 免费额度用完：换备选工具，或第二天再试。
